Q6 — Concept — Write a function pipeline(data, funcs) that takes a list and a list 
of functions, and applies each function to the data one after another, passing the 
result of each into the next.

python
double  = lambda x: [i * 2 for i in x]
add_ten = lambda x: [i + 10 for i in x]
keep_even = lambda x: [i for i in x if i % 2 == 0]

pipeline([1, 2, 3, 4], [double, add_ten, keep_even])
# double → [2,4,6,8]
# add_ten → [12,14,16,18]
# keep_even → [12,14,16,18]  ← all even here, but try other inputs
Output: [12, 14, 16, 18]

💡 This is how real data pipelines work. Each function is a transformation stage.
