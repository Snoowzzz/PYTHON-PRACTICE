# Q1. [OOP + loops/lists] — Playlist
# Create a class Playlist with __init__(self, songs) where songs is a
# list of (title, duration_in_minutes) tuples. Add total_duration()
# that loops through songs and returns the sum of all durations.
#
# Input:  songs = [("Blinding Lights", 3), ("Levitating", 4), ("Peaches", 3)]
# Output: total_duration() -> 10
#
# 💡 Adversarial: empty songs list (should return 0), single song.


# Q2. [OOP + dict] — Inventory
# Create a class Inventory with __init__(self) starting with an empty
# dict self.stock. Add add_item(name, qty) — if name exists, increase
# its quantity; if not, add it. Add total_items() returning the sum
# of all quantities.
#
# Input:  add_item("apple", 5); add_item("banana", 2); add_item("apple", 3)
# Output: self.stock -> {"apple": 8, "banana": 2}
#         total_items() -> 10
#
# 💡 Adversarial: add_item with qty=0, calling total_items() on an
# empty inventory (should return 0).

#
# Input:  text = "Hello World this is Python"
# Output: word_count() -> 5
#         shout() -> "HELLO WORLD THIS IS PYTHON"
#
# 💡 Adversarial: text with extra spaces ("  Hi   there  "), empty string.


# Q4. [OOP + lambda/sorted] — Leaderboard
# Create a class Leaderboard with __init__(self, players) where players
# is a list of (name, score) tuples. Add top_player() returning the
# name with the highest score — use sorted() with a lambda key, no
# manual loop.
#
# Input:  players = [("Soham", 91), ("Riya", 95), ("Arjun", 72)]

# 💡 Adversarial: two players tied for highest score — decide and
# document what your function does (returns first found is fine,
