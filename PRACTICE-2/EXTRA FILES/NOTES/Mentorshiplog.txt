## SYNTAX REFERENCE (Quick Lookup)

### Dict
```python
d = {"name": "Soham", "score": 91}
d["name"]           # access
d["score"] = 95     # update
"name" in d         # check key exists
d.get("score", 0)   # access with fallback
```

### Tuple
```python
t = ("a", 3)
t[0]        # → "a"
t[1]        # → 3
char, count = t  # unpack
```

### Sorted with Lambda
```python
sorted(lst, key=lambda x: (-x[1], x[0]))
# Sort by second element descending, first element ascending for ties
```
